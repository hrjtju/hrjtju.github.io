4.2.1 非预期过程

考虑定义在某个概率空间 (Ω,U,P)(\Omega, \mathcal{U}, P)(Ω,U,P) 上的 Brown 运动 W(⋅)W(\cdot)W(⋅)。我们先给出一些定义

定义 4.11 （Brown 运动的历史和未来） 在某个概率空间 (Ω,U,P)(\Omega, \mathcal{U}, P)(Ω,U,P) 上的 Brown 运动 W(⋅)W(\cdot)W(⋅)，定义下面两个 σ\sigmaσ-代数

\begin{align} \mathcal{W}(t) &:= \mathcal{U}(W(s)|0 \leqslant s \leqslant t)\\\mathcal{W}^{+}(t) &:= \mathcal{U}(W(s)-W(t)| s \geqslant t) \end{align}

分别为 Brown 运动从开始截止到 ttt 的 历史，以及 Brown 运动在时间 ttt 之后的 未来 。

定义 4.12 （非预期的 σ\sigmaσ-代数 / 滤子） 考虑一族 σ\sigmaσ-代数 F(⋅)\mathcal{F}(\cdot)F(⋅)，如果它满足

  1. 对所有 0⩽s⩽t0 \leqslant s \leqslant t0⩽s⩽t 有 F(s)⊂F(t)\mathcal{F}(s) \subset \mathcal{F}(t)F(s)⊂F(t)
  2. 对所有 t⩾0t \geqslant 0t⩾0，有 W(t)⩽F(t)\mathcal{W}(t) \leqslant \mathcal{F}(t)W(t)⩽F(t)
  3. 对所有 t⩾0t \geqslant 0t⩾0，F(t)\mathcal{F}(t)F(t) 和 W+(t)\mathcal{W}^{+}(t)W​+​​(t) 相互独立 我们称其相对于 W(⋅)W(\cdot)W(⋅) 是 非预期的，或者称其为 滤子。

注释 4.13 我们可以这样理解 F(t)\mathcal{F}(t)F(t)：它是 ttt 时刻时我们能掌握到的所有信息。一个很自然的想法就是这样定义

F(t):=U(W(s)(0⩽s⩽t),X0)\mathcal{F}(t) := \mathcal{U}\big( W(s)\quad(0 \leqslant s \leqslant t), X_{0} \big) F(t):=U(W(s)(0⩽s⩽t),X​0​​)

其中 X0X_{0}X​0​​ 是一个和 W+(0)\mathcal{W}^{+}(0)W​+​​(0) 无关的随机变量。事实上，X0X_{0}X​0​​ 就是后面讲到的 SDE 中的 初值条件。

定义 4.14 （非预期的随机过程） 如果一个实值随机过程 G(⋅)G(\cdot)G(⋅) 满足对任意 t⩾0t \geqslant 0t⩾0，G(t)G(t)G(t) 都是 F(t)\mathcal{F}(t)F(t)-可测的，那么就称该随机过程是对 F(⋅)\mathcal{F}(\cdot)F(⋅) 非预期的。

注释 4.15 这个定义可以解释为，任何时刻下，G(t)G(t)G(t) 都只依赖 F(t)\mathcal{F}(t)F(t) 中的信息

注释 4.16 事实上我们其实依赖更强的条件，即 G(⋅)G(\cdot)G(⋅) 需要是 循序可测 (progressively measurable) 的，但这个定义比较复杂，因此我们在此只写它是可测的。前者的主要想法是，在 G(⋅)G(\cdot)G(⋅) 是非预期的基础上，它还同时对 ttt 和 ω\omegaω 联合可测。
事实上，如果被积随机过程 G(⋅)G(\cdot)G(⋅) 是循序可测的，那么对应的 Itô 随机积分 ∫0TGdW\displaystyle \int_{0}^{T} {G} \, \mathrm d{W}∫​0​T​​GdW 的能写成更加简洁优美又实用的形式。换言之，让 G(⋅)G(\cdot)G(⋅) 只和 Brown 运动的历史相关，而不与其未来相关，世界会更美好。

定义 4.17 （循序可测的实值随机过程空间） 定义满足 E(∫0TG2dt)<∞\displaystyle E\left( \int_{0}^{T} {G^{2} } \, \mathrm d{t} \right) < \inftyE(∫​0​T​​G​2​​dt)<∞ 的所有循序可测的实值随机过程 G(⋅)G(\cdot)G(⋅) 构成的空间为 L2(0,T)\mathbb{L}^{2}(0, T)L​2​​(0,T) 定义满足 E(∫0T∣F∣dt)<∞\displaystyle E\left( \int_{0}^{T} |F| \, \mathrm d{t} \right) < \inftyE(∫​0​T​​∣F∣dt)<∞ 的所有循序可测的实值随机过程 F(⋅)F(\cdot)F(⋅) 构成的空间为 L1(0,T)\mathbb{L}^{1}(0, T)L​1​​(0,T)

4.2.2 阶梯过程

为了得出一般形式的 Ito 随机积分，我们从性质更好的阶梯过程开始。

定义 4.18 （阶梯过程） 对一个随机过程 G∈L2(0,T)G \in \mathbb{L}^{2}(0, T)G∈L​2​​(0,T) ，如果存在一个 [0,T][0, T][0,T] 上的划分 P={0=t0<t1<⋯<tm=T}P = \{ 0 = t_{0} < t_{1} < \cdots < t_{m} = T \}P={0=t​0​​<t​1​​<⋯<t​m​​=T} 使得对所有 k=0,\dots,m−1k = 0, \dots, m-1k=0,\dots,m−1 和 t∈[tk,tk+1)t \in [t_{k}, t_{k+1})t∈[t​k​​,t​k+1​​)，都有 G(t)≡GkG(t) \equiv G_{k}G(t)≡G​k​​，则 G(⋅)G(\cdot)G(⋅) 被称为是一个 阶梯过程 。

由于上面定义的 GGG 是循序可测的，因此它也是非预期的（对 ω\omegaω 和 ttt 联合可测蕴含对 ttt 可测）。因此 GkG_{k}G​k​​ 是 F(tk)\mathcal{F}(t_{k})F(t​k​​)-可测的随机变量。

定义 4.19 考虑阶梯过程 G∈L2(0,T)G \in \mathbb{L}^{2}(0, T)G∈L​2​​(0,T)，则下面给出了 GGG 在区间 (0,T)(0, T)(0,T) 上的 Ito 随机积分：

∫0TGdW:=∑k=0m−1Gk[W(tk+1)−W(tk)]\int_{0}^{T} {G} \, \mathrm d{W} := \sum\limits_{k=0}^{m-1} G_{k}\big[ W(t_{k+1})-W(t_{k}) \big] ∫​0​T​​GdW:=​k=0​∑​m−1​​G​k​​[W(t​k+1​​)−W(t​k​​)]

这是一个随机变量。

引理 4.20 对所有 a,b∈Ra, b \in \mathbb{R}a,b∈R 以及所有阶梯过程 G,H∈L2(0,T)G, H \in \mathbb{L}^{2}(0, T)G,H∈L​2​​(0,T)，Ito 随机积分有下面的性质

  1. （线性性）∫0TaG+bHdW=a∫0TGdW+b∫0THdW\displaystyle \int_{0}^{T} {aG + bH} \, \mathrm d{W} = a\int_{0}^{T} {G} \, \mathrm d{W} + b\int_{0}^{T} {H} \, \mathrm d{W}∫​0​T​​aG+bHdW=a∫​0​T​​GdW+b∫​0​T​​HdW
  2. （期望为零）E(∫0TGdW)=0\displaystyle E\left( \int_{0}^{T} {G} \, \mathrm d{W} \right) = 0E(∫​0​T​​GdW)=0
  3. E[(∫0TGdW)2]=E(∫0TG2dt)\displaystyle E\left[ \left( \int_{0}^{T} {G} \, \mathrm d{W} \right)^{2} \right]= E\left( \int_{0}^{T} {G^{2} } \, \mathrm d{t} \right)E[(∫​0​T​​GdW)​2​​]=E(∫​0​T​​G​2​​dt)

证明. （1）可以看见，两个阶梯过程的线性组合是一个新的阶梯过程。 （2）

\begin{align} E\left( \int_{0}^{T} {G} \, \mathrm d{W} \right) &= E\left[ \sum\limits_{k=1}^{m-1} G_{k} \left[ W(t_{k+1}) - W(t_{k})\right] \right] \end{align}

由于 GkG_{k}G​k​​ 是 F(tk)\mathcal{F}(t_{k})F(t​k​​)-可测的，W(tk+1)−W(tk)W(t_{k+1}) - W(t_{k})W(t​k+1​​)−W(t​k​​) 是 W+(tk)\mathcal{W}^{+}(t_{k})W​+​​(t​k​​) 可测的。因此 GkG_{k}G​k​​ 和 W(tk+1)−W(tk)W(t_{k+1}) - W(t_{k})W(t​k+1​​)−W(t​k​​) 无关，因此有上式等于零 （3）先展开

\begin{align} E\left[ \left( \int_{0}^{T} {G} \, \mathrm d{W} \right)^{2} \right] &= E\left[ \sum\limits_{i,j} \underbrace{ G_{i} }_{ \in \mathcal{F}(t_{i}) } \cdot \underbrace{ G_{j} }_{ \in\mathcal{F}(t_{j}) } \cdot \underbrace{ [W(t_{i+1}) - W(t_{i})] }_{ \in\mathcal{W}^{+}(t_{i}) } \cdot\underbrace{ [W(t_{j+1}) - W(t_{j})] }_{ \in\mathcal{W}^{+}(t_{j}) } \right] \\ &= \sum\limits_{i,j}E\left[ \underbrace{ G_{i} }_{ \in \mathcal{F}(t_{i}) } \cdot \underbrace{ G_{j} }_{ \in\mathcal{F}(t_{j}) } \cdot \underbrace{ [W(t_{i+1}) - W(t_{i})] }_{ \in\mathcal{W}^{+}(t_{i}) } \cdot\underbrace{ [W(t_{j+1}) - W(t_{j})] }_{ \in\mathcal{W}^{+}(t_{j}) } \right] \end{align}

其中 i<ji < ji<j 时，有 W(tj+1)−W(tj)W(t_{j+1}) - W(t_{j})W(t​j+1​​)−W(t​j​​) 和乘起来的其他三项相互独立，因此它们的期望为零。类似地也可以得到 i>ji > ji>j 时的所有求和项期望都是零。因此可以简化为

\begin{align} E\left[ \left( \int_{0}^{T} {G} \, \mathrm d{W} \right)^{2} \right] &= \sum\limits_{i =1}^{m-1}E\left[ G_{i}^{2} [W(t_{i+1}) - W(t_{i})]^{2} \right] \\ &= \sum\limits_{i =1}^{m-1}E(G_{i}^{2})E ([\underbrace{ W(t_{i+1}) - W(t_{i}) }_{ \sim N(0, t_{i+1}-t_{i}) }]^{2}) \\ &= \sum\limits_{i =1}^{m-1}E(G_{i}^{2})(t_{i+1}-t_{i}) = E\left( \int_{0}^{T} G^{2} \, \mathrm d t \right) \\ \end{align}

有了阶梯过程后我们就考虑用阶梯过程逼近 L2(0,T)\mathbb{L}^{2}(0, T)L​2​​(0,T) 中的任意随机过程 GGG，这样就可以定义 GGG 的随机 Ito 积分了。

引理 4.21 （用阶梯过程逼近任意二次可积的循序可测随机过程） 任意 G∈L2(0,T)G \in \mathbb{L}^{2}(0, T)G∈L​2​​(0,T)，都存在一列 L2(0,T)\mathbb{L}^{2}(0 ,T)L​2​​(0,T) 中的随机过程 G(n)G^{(n)}G​(n)​​，使得

E(∫0T∣G−G(n)∣dt)→0.E\left( \int_{0}^{T} |G - G^{(n)}| \, \mathrm dt \right) \rightarrow 0. E(∫​0​T​​∣G−G​(n)​​∣dt)→0.

证明思路. 大概的思路就是对几乎一定连续的随机过程 GGG ，对 [0,T][0, T][0,T] 这个区间画格子，并定义

G(m)(t):=∫0tmem(s−t)G(s)dsG^{(m)}(t) := \int_{0}^{t} {me^{m(s-t)}G(s)} \, \mathrm d{s} G​(m)​​(t):=∫​0​t​​me​m(s−t)​​G(s)ds

所得的 G(m)(t)G^{(m)}(t)G​(m)​​(t) 对几乎所有 ω\omegaω 都连续，且几乎一定二次收敛到 GGG。接着就用阶梯过程逼近 G(m)G^{(m)}G​(m)​​。
