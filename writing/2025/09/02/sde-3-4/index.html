3.4 采样路径的性质

本节中我们将见到，对样本空间 Ω\OmegaΩ 中几乎所有样本点 ω\omegaω，采样路径 t↦W(t,ω)t \mapsto \mathbf{W}(t, \omega)t↦W(t,ω) 在指数 γ∈(0,12)\displaystyle \gamma \in \left(0, \frac{1}{2}\right)γ∈(0,​2​​1​​) 时都是一致 Hölder 连续的，而对任意 γ>12\gamma > \displaystyle\frac{1}{2}γ>​2​​1​​ 是无处 Hölder 连续的。除此之外，采样路径是几乎一定处处不可微的，且在任意区间的变差都是无穷大。

3.4.1 采样路径的连续性

首先给出一致 Hölder 连续的定义

定义 3.16 （ γ\gammaγ-Hölder 连续） 函数 f:[0,T]→Rf:[0, T] \rightarrow \mathbb{R}f:[0,T]→R 若在 sss 处满足对任意 t∈[0,T]t \in [0, T]t∈[0,T]，都存在 KKK，有

∣f(t)−f(s)∣⩽K∣t−s∣γ|f(t)-f(s)| \leqslant K|t-s|^{\gamma} ∣f(t)−f(s)∣⩽K∣t−s∣​γ​​

我们称它在 sss 处 γ\gammaγ-Hölder 连续。

定义 3.17 （一致 γ\gammaγ-Hölder 连续） 函数 f:[0,T]→Rf:[0, T] \rightarrow \mathbb{R}f:[0,T]→R 若对任意 s,t∈[0,T]s,t \in [0, T]s,t∈[0,T]，都存在 KKK，有

∣f(t)−f(s)∣⩽K∣t−s∣γ|f(t)-f(s)| \leqslant K|t-s|^{\gamma} ∣f(t)−f(s)∣⩽K∣t−s∣​γ​​

我们称它在 [0,T][0, T][0,T] 上一致 γ\gammaγ-Hölder 连续。

接下来的定理属于 Kolmogorov，是判定 Hölder 连续性的重要工具

定理 3.18 （Kolmogorov，采样路径的 Hölder 连续性） 几乎所有采样路径都连续的随机过程 X(⋅)\mathbf{X}(\cdot)X(⋅) 若满足存在 α,β>0\alpha, \beta > 0α,β>0，C⩾0C \geqslant 0C⩾0，对任意 t,s⩾0t, s \geqslant 0t,s⩾0，它的几乎所有采样路径都满足

E(∣X(t)−X(s)∣β)⩽C∣t−s∣1+αE(|\mathbf{X}(t) - \mathbf{X}(s)|^{\beta}) \leqslant C|t-s|^{1+\alpha} E(∣X(t)−X(s)∣​β​​)⩽C∣t−s∣​1+α​​

则对几乎所有 ω\omegaω、任意 T>0T > 0T>0 和任意 γ∈(0,αβ)\displaystyle \gamma \in \left(0, \frac{\alpha}{\beta}\right)γ∈(0,​β​​α​​)，都存在一个常数 K=K(ω,γ,T)K=K(\omega, \gamma, T)K=K(ω,γ,T) 使得对任意 s,t∈[0.T]s, t \in [0. T]s,t∈[0.T]，有

∣X(s,ω)−X(t,ω)∣⩽K∣t−s∣γ|\mathbf{X}(s, \omega) - \mathbf{X}(t, \omega)| \leqslant K|t-s|^{\gamma} ∣X(s,ω)−X(t,ω)∣⩽K∣t−s∣​γ​​

也即 X(⋅,ω)\mathbf{X}(\cdot, \omega)X(⋅,ω) 在 [0,T][0, T][0,T] 上一致 γ\gammaγ-Hölder 连续。

定理证明从略。其证明过程稍作修改可以揭示下面这件事。如果存在一个常数 CCC，使得随机过程 X(⋅)\mathbf{X}(\cdot)X(⋅) 满足

E(∣X(t)−X(s)∣β)⩽C∣t−s∣1+α,α,β>0E(|\mathbf{X}(t)-\mathbf{X}(s)|^{\beta}) \leqslant C|t-s|^{1+\alpha}, \quad \alpha, \beta >0 E(∣X(t)−X(s)∣​β​​)⩽C∣t−s∣​1+α​​,α,β>0

那么它的一个版本（概率意义下和 X(⋅)\mathbf{X}(\cdot)X(⋅) 相等）X~(⋅)\tilde{\mathbf{X} }(\cdot)​X​~​​(⋅) 满足对几乎所有采样路径，以及所有 γ∈(0,αβ)\displaystyle \gamma \in \left(0, \frac{\alpha}{\beta}\right)γ∈(0,​β​​α​​) 都是 γ\gammaγ-Hölder 连续的。

最后我们来看 Brown 运动的 Hölder 连续性。

定理 3.19 （Brown 运动采样路径的连续性） 对所有 γ∈(0,12)\displaystyle \gamma \in \left( 0, \frac{1}{2} \right)γ∈(0,​2​​1​​) ，Brown 运动的采样路径 t↦W(t,ω)t \mapsto \mathbf{W}(t, \omega)t↦W(t,ω) 对几乎所有 ω\omegaω 在 [0,T][0, T][0,T] 上一致 γ\gammaγ-Hölder 连续

我们要用到定理 3.18。首先想到 W(t)−W(s)∼N(0,(t−s)I)\mathbf{W}(t) - \mathbf{W}(s) \sim N(\mathbf{0}, (t-s)\mathbf{I})W(t)−W(s)∼N(0,(t−s)I)，因此不等式左边的期望就比较好处理，我们考虑整数 m=1,\dotsm=1, \dotsm=1,\dots，然后让左边的指数是 2m2m2m，方便操作：

\begin{aligned} E(|\mathbf{W}(t)-\mathbf{W}(s)|^{2m}) &= \frac{1}{(2\pi r)^{n/2} } \int_{\mathbb{R}^{n} } \| \mathbf{x} \| ^{2m} \exp\left\{ -\frac{\|\mathbf{x}\|^{2} }{2r} \right\} \, \mathrm{d} \mathbf{x} & r \leftarrow t - s\\ &= r^{m} \cdot {\color{red} \frac{1}{(2\pi)^{n/2} } \int_{\mathbb{R}^{n} } \| \mathbf{y} \| ^{2m} \exp\left\{ -\frac{\|\mathbf{y}\|^{2} }{2} \right\} \, \mathrm{d} \mathbf{y} } & \mathbf{y} \leftarrow \frac{\mathbf{x} }{\sqrt{ r } } \\ &= {\color{red} C } r^{m} = C|t-s|^{m} \end{aligned}

所以上面的定理在这里用的话，对所有的 α=m−1\alpha = m-1α=m−1，β=2m\beta=2mβ=2m 都成立，因此 Brown 运动在 R⩾0\mathbb{R}_{\geqslant {0} }R​⩾0​​ 上对所有 0<γ<αβ=12−12m\displaystyle 0 < \gamma < \frac{\alpha}{\beta}= \frac{1}{2} - \frac{1}{2m}0<γ<​β​​α​​=​2​​1​​−​2m​​1​​ 都 γ\gammaγ-Hölder 连续。因为对所有 mmm 成立，取极限就得到了结果。

3.4.2 无处可微性

最后我们来证 Brown 运动的采样序列在 γ>12\displaystyle \gamma > \frac{1}{2}γ>​2​​1​​ 时依概率处处 γ\gammaγ-Hölder 不连续。

定理 3.20 Brown 运动的采样路径在 12<γ⩽1\displaystyle \frac{1}{2} <\gamma \leqslant1​2​​1​​<γ⩽1 时依概率处处 γ\gammaγ-Hölder 不连续，不可微，且在定义域中的任意区间上有无限变差。

证明. 我们只证一维的情形，不失一般性，我们只考虑 [0,1][0, 1][0,1] 上的情况。先找一个很大的 NNN，使得

N(γ−12)>1N\left(\gamma-\frac{1}{2}\right) > 1 N(γ−​2​​1​​)>1

假设 t↦W(t,ω)t\mapsto W(t, \omega)t↦W(t,ω) 在某点 sss 处 γ\gammaγ-连续，按照定义，我们知道对任意 t∈[0,1]t \in [0, 1]t∈[0,1]，存在某个尝试 KKK，使得

∣W(t,ω)−W(s,ω)∣⩽K∣t−s∣γ|W(t, \omega) - W(s, \omega)| \leqslant K|t-s|^{\gamma} ∣W(t,ω)−W(s,ω)∣⩽K∣t−s∣​γ​​

然后考虑一个大数 n≫1n \gg 1n≫1，和指标 i=[ns]+1i = [ns]+1i=[ns]+1，以及 j=i,i+1,\dots,i+N−1j = i, i+1, \dots, i+N-1j=i,i+1,\dots,i+N−1。这是为了离散化时间轴，将 [0,1][0, 1][0,1] 切成 nnn 份，然后将 sss 所在的那一份的右侧离散点开始分析，再往右数 N−1N-1N−1 个离散点。接下来考虑某个采样路径在两个相邻离散点之处的函数值差的绝对值

\begin{aligned} \left| W\left( \frac{j}{n}, \omega \right) - W\left( \frac{j+1}{n}, \omega \right) \right| &\leqslant \left| W\left( s, \omega \right) - W\left( \frac{j}{n}, \omega \right) \right| + \left| W\left( s, \omega \right) - W\left( \frac{j+1}{n}, \omega \right) \right|& 三角不等式\\ &\leqslant K\left[ \left| s-\frac{j}{n} \right|^{\gamma} + \left| s-\frac{j+1}{n} \right|^\gamma \right] \leqslant \frac{M}{n^{\gamma} } \end{aligned}

其中 MMM 是某个常数。因此这个样本点 ω\omegaω 位于下面的事件中：

AM,n(i)\coloneqq{∣W(jn)−W(j+1n)∣⩽Mnγ,j=i,\dots,i+N−1}A_{M, n}^{(i)} \coloneqq \left\{ \left| W\left( \frac{j}{n} \right)- W\left( \frac{j+1}{n} \right) \right| \leqslant \frac{M}{n^{\gamma} }, j = i, \dots, i+N-1 \right\} A​M,n​(i)​​\coloneqq{​∣​∣​∣​∣​​W(​n​​j​​)−W(​n​​j+1​​)​∣​∣​∣​∣​​⩽​n​γ​​​​M​​,j=i,\dots,i+N−1}

这个集合的意义是，给定划分细度 nnn 下，从 sss 右侧第一个离散点开始（包括第一个）的 NNN 个离散点分割得到的若干区间中，采样序列在每个小区间的增量绝对值 Mnγ\displaystyle\frac{M}{n^{\gamma} }​n​γ​​​​M​​。 所以样本空间中满足采样路径在 [0,1][0, 1][0,1] 上某点 sss 处 γ\gammaγ-Hölder 连续的所有样本点构成的集合一定被包含在下面的集合中：

⋃M=1∞⋃k=1∞⋂n=k∞⋃i=1nAM,n(i)\bigcup_{M=1}^{\infty}\bigcup_{k=1}^{\infty}\bigcap_{n=k}^{\infty}\bigcup_{i=1}^{n} A_{M, n}^{(i)} ​M=1​⋃​∞​​​k=1​⋃​∞​​​n=k​⋂​∞​​​i=1​⋃​n​​A​M,n​(i)​​

  • 第一层表示从 iii 开始往后数 N−1N-1N−1 个格子，采样路径每格变化有限的样本点；它包含了所有在离散点 iii 处满足 γ\gammaγ-Hölder 连续（且增量被 MMM 相关的函数控制）的样本点。
  • 第二层和第三层收集所有从不同的 kkk 开始一直加细到无穷大，满足每格增量都有限的样本点，也就是加细分割时 ⋃i=1nAM,n(i)\displaystyle \bigcup_{i=1}^{n} A_{M, n}^{(i)}​i=1​⋃​n​​A​M,n​(i)​​ 稳定发生的样本点，这一步是在调整包含集合，被 MMM 控制的使得采样路径 γ\gammaγ-Hölder 连续的样本点仍然被包含在内。这两步是服务后续估计的。
  • 最外一层逐渐放开上界 MMM，这样就包含了所有的 γ\gammaγ-Hölder 连续的函数

接下来要做的读者也许就能猜到，就是要证这个包含集合的概率是零。对所有 kkk 和 MMM，估计里面两层的概率

P(⋂n=k∞⋃i=1nAM,n(i))⩽liminfn→∞P(⋃i=1nAM,n(i))⩽liminfn→∞∑i=1nP(AM,n(i))⩽liminfn→∞n⋅[P(∣W(1n)⩽Mnγ∣)]nW(j+1n)−W(jn)∼W(1n)\begin{aligned} P\left( \bigcap_{n=k}^{\infty}\bigcup_{i=1}^{n} A_{M, n}^{(i)} \right) &\leqslant \liminf_{ n \to \infty } P\left( \bigcup_{i=1}^{n} A_{M, n}^{(i)} \right) \\ &\leqslant \liminf_{ n \to \infty } \sum_{i=1}^{n} P\left(A_{M, n}^{(i)} \right) \\ &\leqslant \liminf_{ n \to \infty } n \cdot \left[ P\left( \left|W\left( \frac{1}{n} \right) \leqslant \frac{M}{n^{\gamma} } \right| \right) \right] ^{n} & W\left( \frac{j+1}{n} \right) - W\left( \frac{j}{n} \right) \sim W\left( \frac{1}{n} \right) \end{aligned} ​P(​n=k​⋂​∞​​​i=1​⋃​n​​A​M,n​(i)​​)​​​​​⩽​n→∞​liminf​​P(​i=1​⋃​n​​A​M,n​(i)​​)​⩽​n→∞​liminf​​​i=1​∑​n​​P(A​M,n​(i)​​)​⩽​n→∞​liminf​​n⋅[P(​∣​∣​∣​∣​​W(​n​​1​​)⩽​n​γ​​​​M​​​∣​∣​∣​∣​​)]​n​​​​​W(​n​​j+1​​)−W(​n​​j​​)∼W(​n​​1​​)​​

现在来看括号里面的东西。

P(∣W(1n)⩽Mnγ∣)=12πn−1∫−Mn−γMn−γexp{−nx22}dx=12π∫−Mn1/2−γMn1/2−γexp{−y22}dyy←n⋅x⩽Cn1/2−γ\begin{aligned} P\left( \left|W\left( \frac{1}{n} \right) \leqslant \frac{M}{n^{\gamma} } \right| \right) &= \frac{1}{\sqrt{ 2\pi n^{-1} } }\int_{-Mn^{-\gamma} }^{Mn^{-\gamma} } \exp\left\{ -\frac{nx^{2} }{2} \right\} \, \mathrm{d}x \\[0.5em] &= \frac{1}{\sqrt{ 2\pi } }\int_{-Mn^{1/2-\gamma} }^{Mn^{1/2-\gamma} } \exp\left\{ -\frac{y^{2} }{2} \right\} \, \mathrm{d}y & y \leftarrow \sqrt{ n } \cdot x\\[0.5em] &\leqslant Cn^{1/2-\gamma} \end{aligned} ​P(​∣​∣​∣​∣​​W(​n​​1​​)⩽​n​γ​​​​M​​​∣​∣​∣​∣​​)​​​​​=​√​2πn​−1​​​​​​​1​​∫​−Mn​−γ​​​Mn​−γ​​​​exp{−​2​​nx​2​​​​}dx​=​√​2π​​​​​1​​∫​−Mn​1/2−γ​​​Mn​1/2−γ​​​​exp{−​2​​y​2​​​​}dy​⩽Cn​1/2−γ​​​​​y←√​n​​​⋅x​​

所以可以计算上面概率的一个上界：

P(⋂n=k∞⋃i=1nAM,n(i))⩽liminfn→∞nC[n1/2−γ]N=0\begin{aligned} P\left( \bigcap_{n=k}^{\infty}\bigcup_{i=1}^{n} A_{M, n}^{(i)} \right) &\leqslant \liminf_{ n \to \infty } nC[n^{1/2-\gamma}]^{N} = 0 \end{aligned} ​P(​n=k​⋂​∞​​​i=1​⋃​n​​A​M,n​(i)​​)​​​⩽​n→∞​liminf​​nC[n​1/2−γ​​]​N​​=0​​

由于这对所有 kkk 和 MMM 都成立，因此由概率的可数可加性，有

P(⋃M=1∞⋃k=1∞⋂n=k∞⋃i=1nAM,n(i))⩽0.P\left( \bigcup_{M=1}^{\infty}\bigcup_{k=1}^{\infty}\bigcap_{n=k}^{\infty}\bigcup_{i=1}^{n} A_{M, n}^{(i)} \right) \leqslant 0. P(​M=1​⋃​∞​​​k=1​⋃​∞​​​n=k​⋂​∞​​​i=1​⋃​n​​A​M,n​(i)​​)⩽0.

因此出现 γ\gammaγ-Hölder 连续轨道的概率至多是零。

假如轨道在某处可微，那它至少是 111-Hölder 连续的，而这件事发生的概率为零。假如它在某个子区间的变差的有界的，那它一定在那个区间上几乎处处可导，因此这也是几乎不可能的。
