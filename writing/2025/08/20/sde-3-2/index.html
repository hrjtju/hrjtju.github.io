3.2 Brown 运动的基本性质

3.2.1 Brown 运动的定义

上面的内容自然地引出了 Brown 运动，我们在此假设 D=1D=1D=1，然后对它下个定义

定义 3.1 （一维 Brown 运动） 一个一维 Brown 运动（或 Wiener 过程）是指这样的实值随机过程 W(⋅)W(\cdot)W(⋅)，它满足下面的几个条件

  1. W(0)=0a.s.W(0) = 0\quad\text{a.s.}W(0)=0a.s.
  2. 对所有 t⩾s⩾0t \geqslant s \geqslant 0t⩾s⩾0，W(t)−W(s)W(t) - W(s)W(t)−W(s) 服从 N(0,t−s)N(0, t-s)N(0,t−s)
  3. 对所有 0<t1<t2<⋯<tn0 < t_{1} < t_{2} < \cdots < t_{n}0<t​1​​<t​2​​<⋯<t​n​​，随机变量 W(t1),W(t2)−W(t1),\dots,W(tn)−W(tn−1)W(t_{1}), W(t_{2}) - W(t_{1}), \dots, W(t_{n}) - W(t_{n-1})W(t​1​​),W(t​2​​)−W(t​1​​),\dots,W(t​n​​)−W(t​n−1​​) 是相互独立的（增量相互独立）

中心极限定理可以给我们更多启发，Brown 运动中粒子的每次独立随机扰动的加和经过适当缩放调整后就会得出 Gauss 分布（定义中的第二条）。

定理 3.2 W(⋅)W(\cdot)W(⋅) 是一个一维 Brown 运动，对每一个实值函数 f:Rn→Rf: \mathbb{R}^{n} \rightarrow \mathbb{R}f:R​n​​→R 和采样时间序列 0=t0<t1<⋯<tn0 = t_{0} < t_{1} < \cdots < t_{n}0=t​0​​<t​1​​<⋯<t​n​​，有

\begin{align*}&E\Big[f\big(W(t_{1}), \dots, W(t_{n})\big)\Big] \\[0.5em]= &\int_{-\infty}^{\infty} \cdots \int_{-\infty}^{\infty} f(x_{1}, \dots, x_{n})g(x_{1}, t_{1}|0)g(x_{2}, t_{2}-t_{1}|x_{1})\\&\quad\quad\cdots g(x_{n}, t_{n} - t_{n-1}|x_{n-1}) \, \mathrm{d}x_{n} \cdots \, \mathrm{d}x_{1} \end{align*}

3.2.3 白噪声

现在来看看白噪声是怎么回事。

引理 3.3 W(⋅)W(\cdot)W(⋅) 是一个一维 Brown 运动，对 s,t>0s, t > 0s,t>0，有

E(W(t)) = 0, \quad E(W^{2}(t)) = t$$以及$$E(W(t)W(s)) = t \wedge s = \min~\{ s, t \}

(注意，这里的 ∧\wedge∧ 跟微分形式里面那玩意儿没关系，为约定俗成)

证明. 前两个结果容易得到。我们计算最后一个。不妨假设 t>st > st>s，得到

\begin{align*} E\big( W(t)W(s) \big) &= E\Big[ (W(s) + W(t) - W(s))W(s) \Big]\\ &= E\Big[ W(s)^{2} \Big] + E\Big[ (W(t)-W(s))W(s) \Big]\\ &= E\Big[ W(s)^{2} \Big] + \underbrace{ E\Big[W(t)-W(s)\Big]E\Big[W(s) \Big] }_{ 0 } & 增量独立性\\ &= s = t \wedge s \end{align*}

一些直觉推导 我们在介绍 SDE 的时候提到了对 Brown 运动 “求导” 的结果 W˙(t)=ξ(t)\dot{W}(t) = \xi(t)​W​˙​​(t)=ξ(t) 是 “一维白噪声”。但事实上几乎对所有的 ω\omegaω 对应的采样路径 t↦W(t,ω)t \mapsto W(t, \omega)t↦W(t,ω) 对所有 t⩾0t \geqslant 0t⩾0 都是不可微的。因此 W˙(⋅)=ξ(t)\dot{W}(\cdot) = \xi(t)​W​˙​​(⋅)=ξ(t) 这样的东西实际并不存在。但我们有这个启发式公式 \text{“}E\Big[ \xi(t)\xi(s) \Big] = \delta_{0}(s - t)\text{”}。我们可以 “证明” 这件事情。考虑 h>0h > 0h>0，固定 t>0t > 0t>0，然后算一下两个微商的乘积

\begin{align*} \phi_{h}(s) &:= E\left[ \left( \frac{W(t+h) - W(t)}{h} \right)\left( \frac{W(s+h) - W(s)}{s} \right) \right]\\ &= \frac{1}{h^{2} } \Big[ E(W(t+h)W(s+h)) - E(W(t+h)W(s)) \\&\quad\quad- E(W(t)W(s+h)) + E(W(t)W(s)) \Big] \\ &= \frac{1}{h^{2} } \Big[ (t+h)\wedge(s+h) - (t+h)\wedge s - t \wedge (s+h) + t \wedge s \Big] \\ &= \frac{1}{h^{2} }\Big[ 2(t \wedge s) +h - (t+h)\wedge s - ((t - h) \wedge (s) +h)\Big]\\ &= \frac{1}{h^{2} }\Big[ 2(t \wedge s) - (t+h)\wedge s - (t - h) \wedge s \Big]\\ &= \begin{cases} 0,& s < t - h\\ h^{-2}[s-(t-h)],& t-h < s < t\\ h^{-2}[(t+h) - s],& t < s < t+h\\ 0,& s > t + h \end{cases} \end{align*}

可以看到这是一个连续的 “脉冲”，它的高是 1h\displaystyle \frac{1}{h}​h​​1​​，因此曲线下的面积总是 111。令 h→0h \rightarrow 0h→0，函数 ϕh(s)\phi_{h}(s)ϕ​h​​(s) 就会 ”趋于“ Dirac 质量 δ0(s−t)\delta_{0}(s - t)δ​0​​(s−t)，也即 E[ξ(t)ξ(s)]E\Big[ \xi(t)\xi(s) \Big]E[ξ(t)ξ(s)]。

为什么 W˙(⋅)=ξ(⋅)\dot{W}(\cdot) = \xi(\cdot)​W​˙​​(⋅)=ξ(⋅) 叫做 “白噪声” 假设实值随机过程 X(⋅)X(\cdot)X(⋅) 满足对任意 t⩾0t \geqslant 0t⩾0，有 E(X2(t))<∞E(X^{2}(t)) < \inftyE(X​2​​(t))<∞，我们定义 自相似函数 为

r(t,s):=E(X(t)X(s)),t,s⩾0r(t, s) := E(X(t)X(s)), \quad t, s \geqslant 0 r(t,s):=E(X(t)X(s)),t,s⩾0

如果存在某个函数 c:R→Rc: \mathbb{R}\rightarrow \mathbb{R}c:R→R，使得 r(t,s)=c(t−s)r(t, s) = c(t - s)r(t,s)=c(t−s)，除此之外随机过程还满足对任意 t,s⩾0t, s \geqslant 0t,s⩾0 有 E(X(t))=E(X(s))E(X(t)) = E(X(s))E(X(t))=E(X(s))，则我们称 X(⋅)X(\cdot)X(⋅) 是 广义平稳的。白噪声 ξ(⋅)\xi(\cdot)ξ(⋅) 至少在形式上是 Gauss 广义平稳的，这时 c=δ0c = \delta_{0}c=δ​0​​。ξ(⋅)\xi(\cdot)ξ(⋅) 叫做白噪声的原因是频域中它是常函数，这说明每种 “颜色” （频率）的 “光” 的贡献是相同的。定义对 ccc 的 Fourier 变换
